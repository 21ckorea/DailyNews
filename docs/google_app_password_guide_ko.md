# 구글 앱 비밀번호 생성 가이드

Python을 사용하여 Gmail을 통해 이메일을 보내려면 보안상의 이유로 일반 계정 비밀번호 대신 **앱 비밀번호**를 사용해야 합니다.

## 생성 단계

1. **구글 계정 관리**: [Google 계정](https://myaccount.google.com/)으로 이동합니다.
2. **보안 메뉴**: 왼쪽의 **[보안]** 탭을 클릭합니다.
3. **2단계 인증**: **[2단계 인증]**이 '사용'으로 설정되어 있는지 확인합니다.
4. **앱 비밀번호 검색**: 
    - 2단계 인증 메뉴 하단에서 **[앱 비밀번호]**를 찾습니다.
    - 또는 상단 검색창에 "앱 비밀번호"를 검색합니다.
5. **앱 생성**:
    - 이름(예: `Daily News Python`)을 입력하고 **[만들기]**를 클릭합니다.
6. **비밀번호 복사**: 노란색 박스에 표시된 **16자리 비밀번호**를 복사합니다.
7. **설정 업데이트**: 복사한 비밀번호를 `config.yaml`의 `sender_password` 필드에 붙여넣습니다.
