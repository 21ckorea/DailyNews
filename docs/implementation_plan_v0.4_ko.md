# 데일리 뉴스 이메일 시스템 구현 계획 v0.4 (최종 - 동적 분석 기능 포함)

제공해주신 "데이터 분석" 대시보드 이미지를 참고하여, 단순히 키워드를 고정하는 방식이 아니라 **당일 뉴스 언급 횟수를 분석하여 상위 3개 키워드를 선정**하는 고도화된 시스템으로 업데이트를 마쳤습니다.

## 핵심 기능

### 1. 지능형 키워드 선정 (crawler.py)
- 각 카테고리별로 정의된 후보 키워드 리스트 중 당일 뉴스에서 가장 많이 언급된 상위 3개를 자동으로 선정합니다.
- 예: "DB그룹" 관련 뉴스 30여 개를 먼저 분석하여 그중 가장 빈도가 높은 "보험", "DB손해보험", "DB생명" 등을 추출.

### 2. 멀티 소스 통합 분석
- 네이버 뉴스와 구글 뉴스의 방대한 데이터를 바탕으로 분석을 수행하여 신뢰도를 높였습니다.

### 3. 사용자화된 설정 (config.yaml)
- 각 카테고리별로 분석 대상이 될 후보군(candidate_keywords)을 자유롭게 설정할 수 있습니다.

## 사용자를 위한 다음 단계
- **config.yaml**의 `candidate_keywords` 부분에 분석을 원하는 회사명이나 단어를 추가해 보세요.
- 프로그램이 실행될 때마다 실시간으로 뉴스 흐름을 파악하여 가장 중요한 소식을 전달합니다.
