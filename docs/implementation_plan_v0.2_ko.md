# 데일리 뉴스 이메일 시스템 구현 계획 v0.2

이 시스템은 여러 뉴스 소스로부터 사용자가 정의한 키워드 기반 뉴스 기사를 크롤링하고, 제공된 이미지의 "DB Daily News" 레이아웃을 재현하여 매일 아침 8:00에 프리미엄 스타일의 HTML 이메일을 발송합니다.

## 사용자 검토 필요 사항

> [!IMPORTANT]
> **이메일 인증 정보**: 이메일을 보내기 위해 SMTP 설정(예: Gmail 앱 비밀번호)이 필요합니다.
> **뉴스 소스**: 광범위한 커버리지를 보장하기 위해 **멀티 소스 통합**(네이버 뉴스 + 구글 뉴스)을 사용합니다. 이를 통해 주요 언론사부터 니치 블로그까지 모든 매체를 포함합니다.
> **서버 환경**: 매일 오전 8시에 실행하려면 스크립트가 항상 켜져 있는 머신에서 호스팅되어야 합니다.

## 제안된 변경 사항

### 1. 설정 모듈
- **[수정] config.yaml**: 뉴스 소스 선택 및 중복 제거 설정이 추가되었습니다.

### 2. 멀티 소스 뉴스 크롤러 모듈
- **[신규] crawler.py**: 
    - **네이버 뉴스 통합**: 썸네일과 구체적인 언론사 정보(뉴스웨이, 연합뉴스 등)가 포함된 고품질 한국어 뉴스를 위한 기본 소스입니다.
    - **구글 뉴스 통합**: 니치 블로그 및 국제적인 관점을 포함한 더 넓은 범위의 검색을 위한 보조 소스입니다.
    - **중복 제거 로직**: 서로 다른 소스에서 동일한 기사가 중복으로 발송되지 않도록 합니다.
    - **데이터 추출**: 제목, 링크, 언론사, 날짜, 썸네일 URL, 요약문.

### 3. 이메일 템플릿 모듈
- **[수정] templates/news_template.html**:
    - 멀티 소스 데이터를 처리할 수 있도록 향상된 레이아웃.
    - 프리미엄 스타일링: Google Fonts, "출처" 배지가 포함된 카드 디자인.

### 4. 메일러 모듈
- **[신규] mailer.py**: SMTP 연결을 처리하고 HTML 콘텐츠를 발송합니다.

### 5. 메인 실행 및 스케줄러
- **[신규] main.py**: 모든 모듈을 통합하고 `apscheduler`를 사용하여 매일 오전 8시에 실행되는 엔트리 포인트입니다.

## 검증 계획

### 자동 테스트
- 샘플 키워드로 네이버와 구글의 데이터가 올바르게 병합되는지 확인합니다.
- 중복 제거 로직이 예상대로 작동하는지 검증합니다.

### 수동 검증
- 이메일의 시각적 완성도를 확인합니다.
- 오전 8시 트리거가 일관되게 작동하는지 확인합니다.
