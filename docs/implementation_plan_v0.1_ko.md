# 데일리 뉴스 이메일 시스템 구현 계획 v0.1

이 시스템은 사용자가 정의한 키워드를 바탕으로 뉴스 기사를 크롤링하고, 제공된 이미지의 "DB Daily News" 레이아웃을 재현하여 매일 아침 8:00에 프리미엄 스타일의 HTML 이메일을 발송합니다.

## 사용자 검토 필요 사항

> [!IMPORTANT]
> **이메일 인증 정보**: 이메일을 보내기 위해 SMTP 설정(예: Gmail 앱 비밀번호)이 필요합니다.
> **뉴스 소스**: 고품질의 한국어 뉴스 결과를 위해 주로 네이버 뉴스를 사용합니다.
> **서버 환경**: 매일 오전 8시에 실행하려면 스크립트가 항상 켜져 있는 머신(예: 로컬 서버, AWS EC2, 라즈베리 파이 등)에서 호스팅되어야 합니다. 저장소가 프라이빗인 경우 GitHub Actions를 사용하여 스케줄링할 수도 있습니다.

## 제안된 변경 사항

유지보수성을 높이기 위해 시스템은 여러 모듈로 구성됩니다.

### 1. 설정 모듈
- **[신규] config.yaml**: 키워드, 카테고리 및 이메일 설정을 저장합니다.

### 2. 뉴스 크롤러 모듈
- **[신규] crawler.py**: `requests`와 `BeautifulSoup`을 사용하여 네이버에서 뉴스 데이터를 가져옵니다. 다음 정보를 추출합니다:
    - 제목 및 링크
    - 언론사 (뉴스 출처)
    - 상대 날짜 (예: "05월 03일")
    - 썸네일 이미지 URL
    - 키워드/해시태그

### 3. 이메일 템플릿 모듈
- **[신규] templates/news_template.html**: "DB Daily News" 미학에 맞게 설계된 Jinja2 기반 HTML 템플릿입니다.
    - 반응형 3단 레이아웃.
    - 프리미엄 스타일링: Google Fonts (Inter/Outfit), 부드러운 그라데이션, 카드 기반 디자인.

### 4. 메일러 모듈
- **[신규] mailer.py**: SMTP 연결을 처리하고 HTML 콘텐츠를 발송합니다.

### 5. 메인 실행 및 스케줄러
- **[신규] main.py**: 모든 모듈을 통합하고 `apscheduler`를 사용하여 매일 오전 8시에 실행되는 엔트리 포인트입니다.

## 검증 계획

### 자동 테스트
- 샘플 키워드로 크롤러를 테스트하여 데이터 추출이 정상 작동하는지 확인합니다.
- 테스트 이메일을 발송하여 다양한 이메일 클라이언트(Gmail, Outlook)에서 레이아웃과 이미지 렌더링을 확인합니다.

### 수동 검증
- 오전 8시 스케줄이 올바르게 트리거되는지 확인합니다.
- 요청된 디자인과 이메일의 시각적 일치도를 확인합니다.
